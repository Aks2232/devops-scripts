# DevOps Scripts & AWS Automation

A collection of Bash scripts for AWS infrastructure management, monitoring, and automation.

## Scripts

| Script | Description |
|--------|-------------|
| `first-script.sh` | System info + AWS account status check |
| `ec2-manager.sh` | Interactive EC2 start/stop manager |
| `aws-inventory.sh` | Full AWS resource inventory (EC2, S3, IAM, Security Groups) |
| `aws-health-check.sh` | Infrastructure health check with pass/fail reporting |
| `create-iam-user.sh` | Automated IAM user creation and group assignment |

## Tools & Technologies
- Bash scripting
- AWS CLI (EC2, S3, IAM)
- Linux (Ubuntu Server)
- Nginx
